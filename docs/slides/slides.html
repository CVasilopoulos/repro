Vultr Agent Rush, challenge 1: Blast Radius Zero

Bug reports are cheap to write and costly to check

  • The flood is real. curl ended its bug bounty in January 2026 after a surge of AI-written reports that did not hold up.
  • Checking is manual. Clone, install, write a test, then try the reported version and the current one.
  • Checking is risky. A report's "steps to reproduce" are a stranger's code, usually run on a maintainer's own machine.
  • A coding agent makes it riskier if it runs those steps with your keys and your network.
Source on curl: hackaday.com/2026/01/26/the-curl-project-drops-bug-bounties-due-to-ai-slop

Paste an issue URL, get a verdict with the evidence

1. ReadThe issue text is treated as untrusted input.
2. WriteAn agent on Vultr Serverless Inference writes setup.sh and repro.sh in a sandbox. repro.sh exits 1 when the bug happens.
3. VerifyThe backend re-runs both scripts in fresh sandboxes, at the reported commit and on the default branch, twice each.
4. ReportReproduced, fixed (with git bisect naming the commit), not reproducible, flaky or inconclusive.
The verdict comes from exit codes, not from what the model says.

Built on Vultr, with one way out of the sandbox

{{ARCH}}
  • Cloud ComputeOne VM runs Caddy, the FastAPI backend and job queue, the egress gate, and Docker with gVisor.
  • Serverless InferenceEvery model call, through the OpenAI-compatible API. The key stays in the backend.
  • Vultr API and firewalltools/vultr_vm.py creates the VM, SSH key and firewall group, and deletes them again.
  • Each sandboxRead-only root, non-root, no capabilities, 2 GB, 2 CPUs, 256 processes, time limit. Destroyed after its step.

Who it is for, and what a check costs

  • Maintainers: a verified reproduction, or a clear "could not reproduce", before anyone spends an afternoon.
  • Bug bounty and security triage: run a submitted proof of concept with nothing to steal and nowhere to send it.
  • Teams adopting coding agents: the same sandbox and egress design applies to other agent tasks that run untrusted code.
